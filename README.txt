# Sound Objects Archive — Minimal Template (10–30 entries)

This is a no-database website template with:
- Home / Browse / About pages
- Entries (each entry is an HTML page)
- Search + tag filtering (Browse page)

## Edit content
- Update entry metadata in `data/entries.json`
- Edit entry pages in `entries/`
- Customize text in `index.html` and `about.html`

## Publish for free (GitHub Pages)
1. Create a GitHub repo (e.g., `sound-objects-archive`)
2. Upload all files from this folder to the repo root
3. Repo → Settings → Pages
4. Source: Deploy from a branch → `main` → `/ (root)` → Save
5. Your public link will appear (usually `https://<username>.github.io/<repo>/`)

## Audio hosting tip
For big audio files, link or embed from:
- SoundCloud, Internet Archive, or your school storage
Then put the embed/link into an entry page.
