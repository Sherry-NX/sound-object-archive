How to add an entry

  1. Copy entries/003.html and rename it.
  2. Edit the title/metadata/audio embed inside that file.
  3. Add the new entry to data/entries.json.
  4. Commit and publish (GitHub Pages).
Audio tip: host large audio externally (SoundCloud / Internet Archive / school storage) and embed or link.
Made for small archives (10–30 entries). No server required.
